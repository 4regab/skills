# Outreach and notes

## Where to find 10 names

Look where the complaint already is

- Reddit and forum threads that describe the workaround
- App-store 1-star reviews of the incumbent ("I just need X")
- Slack / Discord help channels for a job
- Association directories, shift groups, local Facebook groups
- People the user already works with who live the problem

Do not start with "entrepreneurs on Twitter."

## First message

Short. No pitch deck.

```
Saw you wrote about {their workaround}. I am trying to understand that problem, not sell anything yet. Could I ask how you handled it last time? 10 minutes, your words.
```

If they are in the user's existing network, name the shared context in the first line.

## Notes template

```
Name / role:
Channel:
Last incident:
What they did:
Cost of that:
Tools already paid or installed:
Would they notice if the workaround disappeared this week:
Unprompted ask (quote):
```

Store this in the project as `research.md`. The agent reads it before proposing features.

## Feature rule

A feature needs either

- the same unprompted ask from 3+ notes, or
- money / calendar time already committed

Otherwise it stays off the MVP.
