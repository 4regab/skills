# Graveyard

Compiled from repeated r/SideProject, r/SaaS, and r/AppBusiness rants. Update when a new shape floods those rooms.

## Hot graves

| Category | Usual corpse | Why it dies |
|---|---|---|
| Todo list | Things, Todoist, Apple Reminders, TickTick | Default apps exist. No reason to switch. |
| Habit tracker | Streaks, Habitica, Loop | Tracking is not the hard part. Sticking is. |
| Gym / workout tracker | Strong, Hevy, Apple Fitness | Commodity plus hardware lock-in. |
| Notes / second brain | Notion, Obsidian, Apple Notes | Switching cost is the product. |
| AI chatbot | ChatGPT, Claude, a thousand wrappers | The model vendor is the product. |
| AI PDF summarizer | ChatGPT, Claude projects, dedicated clones | "I built this in 3 hours" is visible to users too. |
| Job board | Indeed, LinkedIn, niche boards that already exist | Supply and demand, not UI. |
| SaaS / tool directory | Product Hunt, There's An AI For That, AlternativeTo | Directories do not get used. They get launched. |
| Social-media scheduler | Buffer, Later, native tools | Crowded, trust + integrations win. |
| Screen-time / focus app | OS built-ins, Freedom, One Sec | Easy to bypass. Users do not want another app. |
| Pomodoro timer | Phone clock, Forest, any timer | Not a company. |
| Generic expense tracker | Banks, Cleo, YNAB, spreadsheets | Data lives in the bank. |
| Resume builder | Existing sites plus Google Docs | Occasional use, brutal SEO incumbents. |
| Link-in-bio | Linktree and copies | Feature is a page. |
| Calendar app | Google / Apple Calendar | Network and defaults. |
| ChatGPT for {industry} with no workflow | the model plus a prompt | Prompt is not a product. |
| Uber for {offline thing} | local incumbents, WhatsApp groups | Marketplace two-sidedness kills solo builders. |

## Warm graves

| Category | When it still might live |
|---|---|
| Productivity suite | Only if it deletes tools, not adds one. "Fewer tools" is the job. |
| Community / social app | Only with a scene that already hangs out somewhere you can stand. |
| Marketplace | Only if one side is already in the room with the builder. |
| Browser extension utility | Small, sharp, installs on an existing habit. Still scan Chrome store. |
| Vertical CRM | Only with a job the builder has done for years. |
| Internal tool turned product | Possible if three other teams already stole the spreadsheet. |

## Failure rhymes (from the rants)

- Built four products, free for two hours, zero signups.
- Six months on a cliché app, $1k in ads, 30 downloads.
- "I built Y in 3 hours" as the new NFT post.
- Next.js + Supabase + five clouds, no user.
- Friends said it looks nice. Nobody paid.
- Product Hunt spike, then silence.
- Feature pile because "what if this is the one."
- Solution looking for a problem (~40% of dead startups cite this).

## Exception test

Keep the idea only if every box is true

- Named scene, not "users"
- Named incumbent they are not trying to out-pretty
- Constraint the incumbent would have to take a loss to copy
- Builder has been in that scene long enough to be believed
- They will talk to 5 people before a second feature

Otherwise it is a grave with a fresh coat of paint.
